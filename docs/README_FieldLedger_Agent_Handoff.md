# FieldLedger Agent Handoff Pack

## Start here
1. Attach `farm_business_ledger_prototype.html` to your coding agent.
2. Open `FieldLedger_Agent_Master_Prompt.txt` and use its entire contents as the task prompt.
3. Optionally include `FieldLedger_Product_Technical_Spec.md` and the original table image for additional context.
4. Tell the agent to inspect the current source first, then execute, run/test, and document its changes. Do not ask it to produce only a plan or a static mockup.

## Files
- `farm_business_ledger_prototype.html` — latest runnable standalone prototype at the time this package was created.
- `FieldLedger_Agent_Master_Prompt.txt` — detailed copy/paste agent prompt.
- `FieldLedger_Product_Technical_Spec.md` — condensed product and technical specification.
- `reference_original_tables.png` — original two-table reference.
- `preview_mobile.png`, `preview_desktop.png`, `preview_bag_modal.png` — prototype screenshots.

## Run the prototype
Open the HTML file in a recent Chrome, Edge, Firefox or Safari browser. No build/install step is needed for the current prototype. Data is stored in the browser's local storage, so export a JSON backup before clearing browser data or switching devices.

## Important limitation
This is a front-end prototype, not a production-hosted app or native Android package. It currently has no backend, authentication, cloud backup or multi-device synchronization.
